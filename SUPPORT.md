# Support

For bugs, feature requests, and questions, open an issue in this repository:

- https://github.com/ota-takeru/gitlab-review-workspace/issues

When reporting a problem, include the following when relevant:

- GitLab Review Workspace version
- VS Code version
- `glab --version`
- GitLab host type (`gitlab.com` or self-managed)
- Reproduction steps and the visible error message

Do not include access tokens, authorization headers, credentials, or private Merge Request content in an issue.
