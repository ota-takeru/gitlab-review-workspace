## 0.0.14

- Isolated review state by GitLab instance and merge request context.
- Preserved failed comment drafts and blocked submissions from stale review contexts.
- Made the VS Code diff editor the primary review surface while retaining the legacy viewer for fallback workflows.
- Added recovery for local drafts created by earlier versions.
- Improved My Work selection and review navigation.

## 0.0.13

- Improved review workflow reliability and UI behavior.
- Refined review state handling across the Sidebar and file review surfaces.

## 0.0.12

- Expanded native VS Code review integration and comment workflows.
- Improved GitLab host handling, review navigation, and local review state.

## 0.0.11 and earlier

- Added GitLab Merge Request browsing, file and commit diffs, threaded discussions, reactions, local edits, image attachments, GitLab Todo navigation, and authenticated host auto-detection.
